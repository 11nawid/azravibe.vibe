What is Azra?

Azra is a lightweight, interpreted language designed for teaching programming concepts and scripting quick tasks. It blends the simplicity of Python with a clear, block-based syntax that feels like natural English — and it uses no brackets.

Basic Syntax

Every Azra program is a series of statements, each ending with a newline. Blocks start with : and are indented by exactly 4 spaces. Comments start with note: or # (or use /* ... */ for a block).

note: A comment starts with note: or #
say "Hello, world!"   note: prints a line

Variables & Types

Declare a variable with set. Types are inferred automatically.

set name to "Alice"
set age to 30
set price to 12.99
set flag to true

Supported primitive types: String, Int, Float, Bool. Collections like list and map are also built-in: set numbers to 1, 2, 3 and set person to empty map.

Control Flow

Use if, while, repeat and for each to direct execution. Comparisons are English words such as greater_than and equals.

set age to 20
if age greater_than 18:
    say "Adult"
otherwise:
    say "Minor"

while flag:
    say "Looping"
    set flag to false

Functions

Define reusable code blocks with define. Parameters follow with, and calls use with too — there are no parentheses.

define greet with name:
    say "Hello, " + name

greet with "Bob"

Modules & Imports

Split your code into files and import them with use.

note: file: math.vibe
define add with a, b:
    give back a + b

note: main.vibe
use "math.vibe"
set result to add with 3, 5
say result

Full Example – A Simple Calculator

This program prints the sum, difference, product and quotient of two set values. Azra has no keyboard-input primitive.

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

Wrap each operation in a function so the arithmetic happens before the label is concatenated.
