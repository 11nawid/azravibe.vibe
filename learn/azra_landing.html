What is Azra?

Azra is a lightweight, interpreted language designed for teaching programming concepts and scripting quick tasks. It blends the simplicity of Python with a clear, block‑based syntax that feels like natural English.

Basic Syntax

Every Azra program is a series of statements, each ending with a newline. Indentation defines blocks (similar to Python).

# A comment starts with a hash
say \"Hello, world!\"   # prints a line

Variables & Types

Declare a variable with set. Types are inferred automatically.

set name to \"Alice\"
set age to 30
set price to 12.99
set flag to true

Supported primitive types: String, Int, Float, Bool. Collections like list and map are also built‑in.

Control Flow

Use if, while, and for to direct execution.

if age > 18:
    say \"Adult\"
else:
    say \"Minor\"

while flag:
    say \"Looping\"
    set flag to false

Functions

Define reusable code blocks with define. Parameters are listed after the name.

define greet name:
    say \"Hello, \" + name

greet \"Bob\"

Modules & Imports

Split your code into files and import them.

# file: math.azra
define add a b:
    give back a + b

# main.azra
use \"math.azra\"
set result to add 3 5
say result

Full Example – A Simple Calculator

This program reads two numbers and prints their sum, difference, product and quotient.

say \"Enter first number:\"
set a to read number
say \"Enter second number:\"
set b to read number

say \"Sum: \" + (a + b)
say \"Difference: \" + (a - b)
say \"Product: \" + (a * b)
if b != 0:
    say \"Quotient: \" + (a / b)
else:
    say \"Cannot divide by zero\"
