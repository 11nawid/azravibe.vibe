Use the set keyword to store values. Types are inferred automatically.

set name to "Alice"
set age to 30
set price to 12.99
set active to true

Collections

List – ordered collection:

set numbers to [1, 2, 3]

Map – key‑value pairs:

set person to {"name": "Bob", "age": 25}
