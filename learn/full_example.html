In this final lesson we combine everything we have learned to build a small calculator script backed by a module. Values are set in the script because Azra has no keyboard-input primitive.

calc.vibe

note: import math helpers
use "math.vibe"

set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

math.vibe

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

Running the program

azra run calc.vibe
Sum: 10
Difference: 6
Product: 16
Quotient: 4
