Azra – Basic Syntax

← Back to Index

Azra programs consist of statements, each ending with a newline. Blocks start with : and are indented by exactly 4 spaces; tabs are not allowed.

Hello World

say "Hello, world!"

Comments

Use note: or # for line comments, and /* ... */ for block comments.

note: This is a comment
# This is also a comment
/* This block
   spans lines */
say "Hi"

Numbers, strings and booleans

set count to 3
set price to 12.99
set name to "Alice"
set active to true

Integer division truncates (say 7 / 2 prints 3). Use a decimal operand for a fractional result (say 7 / 2.0 prints 3.5).
