Welcome

Welcome to the Azra Language tutorial! This guide will take you from zero knowledge to building real programs, step-by-step, using plain English explanations.

What is Azra?

  • A lightweight, interpreted scripting language.
  • Designed for teaching programming concepts and game scripting.
  • Syntax looks like natural English, making it easy to read.
  • Scripts use the .vibe extension.

How to run Azra code

  1. Build the interpreter bundled in this repository with cargo build --release.
  2. Run azra run my_script.vibe from the command line (or just azra my_script.vibe).
  3. Start an interactive REPL with azra repl (or bare azra).

Your first program

say "Hello, world!"

Run it with azra run hello.vibe – you should see Hello, world! printed.
