If / Otherwise

set age to 20
if age greater_than= 18:
    say "Adult"
otherwise:
    say "Minor"

Use otherwise if for extra branches. Comparisons are English words: equals, not_equals, less_than, less_than=, greater_than, greater_than=, is, contains, starts with, has key. Symbolic >= and != are not part of Azra.

While Loop

set counter to 0
while counter less_than 5:
    say counter
    set counter to counter + 1

For Loop (over a list)

set items to "a", "b", "c"
for each item in items:
    say item

repeat 3 times: repeats a fixed count; repeat with i from 1 to 10 by 2: counts over a range. Use stop loop / break and skip next / continue inside loops.
