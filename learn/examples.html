Below are ready-to-run example scripts that demonstrate the concepts covered in the course. Azra has no keyboard-input primitive, so values are set in the script.

Calculator (calculator.vibe)

A simple calculator that uses the math.vibe module.

note: Import math helpers
use "math.vibe"

set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

Output:

Sum: 10
Difference: 6
Product: 16
Quotient: 4

Math Helpers (math.vibe)

Utility module used by the calculator and other programs.

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

This module defines four basic arithmetic functions that return the result.

How to run

From the repository root, run:

azra run learn/examples/calculator.vibe

The script prints the sum, difference, product and quotient.
