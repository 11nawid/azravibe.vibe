Below are ready‑to‑run example scripts that demonstrate the concepts covered in the course.

Calculator (calc.azra)

A simple interactive calculator that uses the math.azra module.

# Import math helpers
use "math.azra"

say "Enter first number:"
set a to read number
say "Enter second number:"
set b to read number

say "Sum: " + add a b
say "Difference: " + sub a b
say "Product: " + mul a b
if b != 0:
    say "Quotient: " + div a b
else:
    say "Cannot divide by zero"

Sample output (enter 8 and 2):

Enter first number:
8
Enter second number:
2
Sum: 10
Difference: 6
Product: 16
Quotient: 4

Math Helpers (math.azra)

Utility module used by the calculator and other programs.

define add a b:
    give back a + b

define sub a b:
    give back a - b

define mul a b:
    give back a * b

define div a b:
    give back a / b

This module defines four basic arithmetic functions that return the result.

How to run

From the repository root, run:

azra learn/examples/calculator.azra

The script will prompt for two numbers and display sum, difference, product, and quotient.
