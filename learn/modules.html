Azra – Modules & Imports

← Back to Index

Split large projects into multiple files. Load a module with use "filename.vibe"; an optional as alias gives it a short name.

Creating a Module (math.vibe)

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

Using the Module

use "math.vibe"
set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

Functions defined in a module are added to the importing script's globals. Import cycles are detected and reported as errors.
