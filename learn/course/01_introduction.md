# Introduction to Azra

Welcome to the **Azra Language** tutorial! This guide will take you from zero knowledge to building real programs, step‑by‑step, using plain English explanations.

## What is Azra?
- A lightweight, interpreted scripting language.
- Designed for teaching programming concepts.
- Syntax looks like natural English, making it easy to read.

## How to run Azra code
1. Install the Azra interpreter (already bundled in this repository).
2. Run `azra` from the command line:
   ```bash
   azra my_script.azra
   ```
3. You can also start an interactive REPL with:
   ```bash
   azra
   ```

## Your first program
Create a file `hello.azra` with:
```azra
say "Hello, world!"
```
Run it:
```bash
azra hello.azra
```
You should see *Hello, world!* printed.
