1. Introduction

Welcome to the Azra Language tutorial! This guide will take you from zero knowledge to building real programs, step‑by‑step, using plain English explanations.

What is Azra?

  • A lightweight, interpreted scripting language.
  • Designed for teaching programming concepts.
  • Syntax looks like natural English, making it easy to read.

How to run Azra code

  1. Install the Azra interpreter (already bundled in this repository).
  2. Run azra my_script.azra from the command line.
  3. Start an interactive REPL with azra.

Your first program

say "Hello, world!"

Run it with azra hello.azra – you should see Hello, world! printed.

2. Basic Syntax

Azra programs consist of statements, each ending with a newline. Indentation defines blocks, similar to Python.

Hello World

say "Hello, world!"

Comments

# This is a comment
say "Hi"

3. Variables & Types

Use the set keyword to store values. Types are inferred automatically.

set name to "Alice"   # String
set age to 30          # Integer
set price to 12.99     # Float
set active to true     # Boolean

Collections

List – ordered collection:

set numbers to [1, 2, 3]

Map – key‑value pairs:

set person to {"name": "Bob", "age": 25}

4. Control Flow

If / Else

if age >= 18:
    say "Adult"
else:
    say "Minor"

While Loop

set counter to 0
while counter < 5:
    say counter
    set counter to counter + 1

For Loop (over a list)

set items to ["a", "b", "c"]
for item in items:
    say item

5. Functions

Defining a Function

define greet name:
    say "Hello, " + name

Calling a Function

greet "Bob"

Returning Values

define add a b:
    give back a + b

set sum to add 3 5
say sum   # prints 8

6. Modules & Imports

Split large projects into multiple files. Load a module with use "filename.azra".

Creating a Module (math.azra)

define add a b:
    give back a + b

define sub a b:
    give back a - b

define mul a b:
    give back a * b

define div a b:
    give back a / b

Using the Module

use "math.azra"
set a to read number
set b to read number

say "Sum: " + add a b
say "Difference: " + sub a b
say "Product: " + mul a b
if b != 0:
    say "Quotient: " + div a b
else:
    say "Cannot divide by zero"

7. Full Example Project – Simple Calculator

Combine everything into a small calculator program.

File structure

learn/course/
├─ math.azra
└─ calc.azra

math.azra (module)

define add a b:
    give back a + b

define sub a b:
    give back a - b

define mul a b:
    give back a * b

define div a b:
    give back a / b

calc.azra (main script)

# Import math helpers
use "math.azra"

say "Enter first number:"
set a to read number
say "Enter second number:"
set b to read number

say "Sum: " + add a b
say "Difference: " + sub a b
say "Product: " + mul a b
if b != 0:
    say "Quotient: " + div a b
else:
    say "Cannot divide by zero"

Running the program

azra calc.azra

You will be prompted for two numbers and see the calculated results.
