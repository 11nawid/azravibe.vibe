1. Introduction

Welcome to the Azra Language tutorial! This guide will take you from zero knowledge to building real programs, step-by-step, using plain English explanations.

What is Azra?

  • A lightweight, interpreted scripting language.
  • Designed for teaching programming concepts and game scripting.
  • Syntax looks like natural English, making it easy to read.

How to run Azra code

  1. Build the interpreter bundled in this repository with cargo build --release.
  2. Run azra run my_script.vibe from the command line.
  3. Start an interactive REPL with azra repl (or bare azra).

Your first program

say "Hello, world!"

Run it with azra run hello.vibe – you should see Hello, world! printed.

2. Basic Syntax

Azra programs consist of statements, each ending with a newline. Blocks start with : and are indented by exactly 4 spaces. There are no brackets anywhere.

Hello World

say "Hello, world!"

Comments

note: This is a comment
# This is also a comment
/* This block
   spans lines */
say "Hi"

3. Variables & Types

Use the set keyword to store values. Types are inferred automatically.

set name to "Alice"   note: text
set age to 30         note: integer
set price to 12.99    note: float
set active to true    note: boolean

Collections

List – ordered collection, written as comma-separated values:

set numbers to 1, 2, 3
add 4 to numbers
remove 2 from numbers
say numbers

Map – string-keyed collection created with empty map:

set person to empty map
set key "name" of person to "Bob"
set key "age" of person to 25
say key "name" of person

4. Control Flow

If / Otherwise

set age to 20
if age greater_than= 18:
    say "Adult"
otherwise:
    say "Minor"

Comparisons are English words: equals, not_equals, less_than, less_than=, greater_than, greater_than=, is, contains, starts with, has key. Symbolic >= and != are not part of Azra.

While Loop

set counter to 0
while counter less_than 5:
    say counter
    set counter to counter + 1

For Loop (over a list)

set items to "a", "b", "c"
for each item in items:
    say item

5. Functions

Defining a Function

define greet with name:
    say "Hello, " + name

Calling a Function

greet with "Bob"

Returning Values

define add with a, b:
    give back a + b

set sum to add with 3, 5
say sum   note: prints 8

6. Modules & Imports

Split large projects into multiple files. Load a module with use "filename.vibe".

Creating a Module (math.vibe)

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

Using the Module

use "math.vibe"
set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

7. Full Example Project – Simple Calculator

Combine everything into a small calculator program. Azra has no keyboard-input primitive, so the values are set in the script.

File structure

learn/course/
├─ math.vibe
└─ calc.vibe

math.vibe (module)

define add with a, b:
    give back a + b

define sub with a, b:
    give back a - b

define mul with a, b:
    give back a * b

define div with a, b:
    give back a / b

calc.vibe (main script)

note: Import math helpers
use "math.vibe"

set a to 8
set b to 2

say "Sum: " + add with a, b
say "Difference: " + sub with a, b
say "Product: " + mul with a, b
if b not_equals 0:
    say "Quotient: " + div with a, b
otherwise:
    say "Cannot divide by zero"

Running the program

azra run calc.vibe
Sum: 10
Difference: 6
Product: 16
Quotient: 4
