## Control Flow

Control structures let you direct the execution of your program.

### If / Else
```azra
if age >= 18:
    say "Adult"
else:
    say "Minor"
```

### While Loop
```azra
set counter to 0
while counter < 5:
    say counter
    set counter to counter + 1
```

### For Loop (over a list)
```azra
set items to ["a", "b", "c"]
for item in items:
    say item
```
