## Variables & Types

Azra lets you store values using the `set` keyword. Types are inferred automatically.

### Declaring Variables
```azra
set name to "Alice"   # String
set age to 30          # Integer
set price to 12.99     # Float
set active to true     # Boolean
```

### Collections
- **List**: ordered collection.
  ```azra
  set numbers to [1, 2, 3]
  ```
- **Map**: key‑value pairs.
  ```azra
  set person to {"name": "Bob", "age": 25}
  ```
