Defining a Function

define greet with name:
    say "Hello, " + name

Calling a Function

greet with "Bob"

Calls in expressions also use with: set message to greet with "Alice".

Returning Values

define add with a, b:
    give back a + b

set sum to add with 3, 5
say sum   note: prints 8

A function with no parameters runs when its name appears in an expression: define status: … give back "ok", then say status.
